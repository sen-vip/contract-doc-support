# 계약서류 작성지원 v0.2.6

업체 제출용 계약서류를 브라우저에서 작성하고 실제 출력 서류를 보면서 확인·인쇄하는 정적 웹앱입니다.

## 지원 서류

- 승낙사항(물품/용역/공사)
- 수의계약 통합서약서
- 공사(용역) 안전·보건 체크리스트(공통)
- 행정정보 공동이용 사전동의서(대금지급 전 4대보험 완납 확인용)




## v0.2.6 변경사항

- 안전·보건 체크리스트 하단 `재해 예방 체크리스트 해당여부` 표를 2열 고정 구조로 재정렬했습니다.
- `해당여부 (○, ×)` 헤더와 아래 O/X 표시 칸의 폭·가로 중앙선·세로 중앙선을 정확히 맞췄습니다.
- 추락·감전·밀폐공간·일반 산업재해 4개 행의 높이와 셀 패딩을 통일해 표선이 삐뚤어 보이지 않도록 정돈했습니다.
- 오른쪽 해당여부 열은 고정 폭으로 유지하고, O/X 기호는 셀 정중앙에 배치되도록 개선했습니다.

## v0.2.5 변경사항

- `서약 항목 ‘예’ 일괄` 등 빠른 입력 버튼을 중립적인 흰색 outline 스타일로 변경해, 실제 선택 상태와 혼동되지 않도록 개선했습니다.
- 파란색은 실제 `예/아니오/해당없음` 선택 상태에만 사용하도록 시각 규칙을 정리했습니다.
- 승낙사항의 `계약조건과 맞는지 확인함` 체크박스와 문구를 수직 중앙 정렬하고, 지연배상금률·하자담보기간·하자기간 확인의 박스 높이와 기준선을 맞췄습니다.

## v0.2.4 변경사항

- 데스크톱에서 왼쪽 실제 서류 미리보기를 workbench 자체에 sticky 고정하여 오른쪽 작성영역을 길게 스크롤해도 항상 좌우가 함께 보이도록 수정
- 좌우 분할 유지 기준을 860px로 조정하여 일반 노트북/데스크톱에서 미리보기가 위로 분리되지 않도록 개선
- 입력항목 클릭 시 실제 문서의 관련 위치를 강조할 때 전체 페이지가 움직이지 않고 왼쪽 미리보기 내부만 스크롤하도록 수정
- 추락·감전·밀폐공간·일반 산업재해 체크리스트 ○/× 클릭 후 상세항목을 렌더링할 때 메인 화면이 맨 위로 이동하지 않도록 수정

## v0.2.3 변경사항

- 데스크톱 작성영역을 **왼쪽 실제 서류 미리보기 / 오른쪽 입력** 구조로 재배치
- 실제 서류 미리보기는 화면에 고정하고, 오른쪽 작성 위치에 따라 현재 문서가 자동 전환
- 문서 선택을 오른쪽 상단의 작은 체크 목록으로 통합하고 별도 `작성` 버튼 제거
- 선택한 서류는 오른쪽에 모두 펼쳐 두고 위에서 아래로 연속 작성
- 수의계약 통합서약서의 아코디언 제거: 기본 서약·체결 제한·보증·기타 확인을 모두 한눈에 표시
- 통합서약서 항목은 큰 카드 대신 행과 구분선 중심으로 경량화
- 출력은 오른쪽 고정 액션바의 `현재 서류 인쇄 / 선택 서류 한 번에 출력`로 종료
- 계약종류별 기본서류, 날짜/사업자번호 포맷, 서명·직인 비영구 저장 등 기존 로직 유지

## 실행

`index.html`을 브라우저에서 열거나 GitHub Pages/Vercel에 정적 배포하면 됩니다.

## 개인정보·저장

사용자가 선택한 업체 기본정보만 브라우저에 저장할 수 있습니다. 계약정보, 생년월일, 체크결과, 서명, 직인 이미지는 영구 저장하지 않습니다.
