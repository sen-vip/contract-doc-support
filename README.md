# 계약서류 작성지원 v0.1.6

계약정보와 업체정보를 한 번 입력해 다음 3종 문서를 작성·미리보기·인쇄하는 정적 웹앱입니다.

- 승낙사항(물품/용역/공사)
- 수의계약 통합서약서
- 공사(용역) 안전·보건 체크리스트(공통)

## v0.1.5 핵심

- 피그마풍 2단 레이아웃 + 모바일 단일 컬럼
- 공사/물품/용역 지연배상금 기본값 자동 적용
- 승낙사항 하자담보기간 기본 1년 + 확인 안내
- 발주기관명과 수신인 분리, 학교·교육청·교육지원청 수신인 추천
- 개인/법인 사업자 유형에 따른 수의계약 체결 제한 `해당없음` 추천
- 업체 기본정보만 선택적으로 `localStorage` 저장
- 직인/서명은 메모리에서만 사용하며 영구 저장하지 않음
- 계약명 등 미입력 상태에서도 빈칸 출력 가능
- 문서별 및 선택 문서 일괄 미리보기/인쇄

## 실행

`index.html`을 브라우저에서 열거나 GitHub Pages/Vercel에 정적 배포하면 됩니다.

## 기준 자료

- 사용자가 제공한 서울특별시교육청 수의계약 통합서약서
- 사용자가 제공한 서울특별시교육청 공사서류 원클릭 프로그램(2026.4.)의 승낙사항 및 안전·보건체크리스트
- 지방자치단체를 당사자로 하는 계약에 관한 법률 시행규칙 제75조(지연배상금률)

> 법령·서식은 개정될 수 있으므로 실제 계약 시 최신 기준을 확인하세요.

## v0.1.4 변경사항

- 계약일·착공/착수일·준공/완료/납품기한 공란 시 `년   월   일` 수기 작성 공간 출력
- 통합서약서 작성 화면의 이행내용 폭 확대 및 `해당없음` 선택영역 넘침 방지
- 통합서약서 인쇄 시 3개 선택지는 `예/아니오`와 `해당없음`을 줄 분리해 원본 구조에 가깝게 표시
- 안전·보건 체크리스트의 점검자 서명은 미리보기·인쇄 직전에 입력하며, 출력 후 즉시 제거
- 서명패드 마우스 커서를 펜 모양으로 변경
- 원클릭 엑셀을 참고해 안전·보건 체크리스트의 점검내용 열은 넓히고 점검결과 3개 열은 좁게 재조정
- `소속(회사)`와 `공사업체 책임자`가 공란이어도 이름·서명을 수기로 쓸 공간 확보
- 수의계약 배제사유 [붙임1]을 번호·본문·참고문구·하위항목으로 나눠 가독성 개선
- 발주기관명 예시를 `학돌중학교`로 변경
